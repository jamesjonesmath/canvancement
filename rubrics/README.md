# Rubrics
These items add functionality to rubrics within Canvas.

## Max Rubrics
Canvas has removed the classic SpeedGrader experience and replaced it with the new Performance and Usability Upgrades for SpeedGrader.
This transition has broken several of my older Canvancements. This is a replacement for some of those written for the new SpeedGrader.
It is a combination of the functionality of Max Ratings and the SpeedGrader portion of QuizWiz.

This is BETA software and not up to my normal level of testing, but I wanted to get something out there for people to use. Be sure to read the documentation and edit the configuration to meet your needs before you start.

* Name: [rubrics/max-rubrics](max-rubrics/)
* Type: [user_script](../USERSCRIPTS.md)
* Browsers: Tested on Chrome, but should work in others.
* Warning: This is beta-software.


## Find Rubric Sorter
When finding an existing rubric, it is difficult to tell which rubrics belong to the current context (course or account). This scripts sorts the rubrics so the current context is at the top and potentially adds additional information to help you distinguish rubrics.

* Name: [rubrics/find-a-rubric](find-a-rubric/)
* Type: [user script](../USERSCRIPTS.md)
* Browsers: Firefox, Chrome, Safari
* Canvas has made their own improvements in this area

## Sort a Rubric
Allows the user to rearrange the rows while editing a rubric.

* Name: [rubrics/sort-rubric](sort-rubric/)
* Type: [user script](../USERSCRIPTS.md)
* Browsers: Firefox, Chrome, Safari

## Import a Rubric
Allows the user to develop a rubric in a spreadsheet and then copy it from the spreadsheet and paste it into Excel.

* Name: [rubrics/import-rubric](import-rubric/)
* Type: [user script](../USERSCRIPTS.md)
* Browsers: Firefox, Chrome, Safari

## Max Ratings
Adds a button to the SpeedGrader rubric that fills all missing ratings with the maximum point values.

* Name: [rubrics/max-ratings](max-ratings/)
* Type: [user script](../USERSCRIPTS.md)
* Browsers: Firefox, Chrome, Safari
* Warning: Broken with the deprecation of classic SpeedGrader 2024-07-18
